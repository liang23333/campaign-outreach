# Door-Knocking Scripts Directory

This folder contains volunteer field guides, voter conversation outlines, and talking points for door-to-door canvassing ahead of the Community Listening Tour.

## Contents
- `canvassing-script.md`: Master door-to-door listening script, question prompts, active listening guidelines, and response handling for neighborhood-specific issues.

## Canvasser Golden Rules
1. **Listen More Than You Talk:** Our primary goal is listening to the resident's lived experience. Aim for 70% resident speaking, 30% canvasser speaking.
2. **Capture Accurate Notes:** Use the campaign canvassing sheet/app to write down specific local concerns and constituent casework requests.
3. **Respect Boundaries:** Never argue. Thank every voter for their time and leave a tour invitation flyer.
