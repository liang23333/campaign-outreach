## 🤝 How Volunteers Can Get Involved

1. **Check the Issues Tab**: Each tour stop has a dedicated GitHub Issue where team captains and volunteers coordinate setup, flyering, tabling, and post-event follow-up.
2. **Download & Distribute Materials**: Access flyers and door-knocking scripts directly from this repository.
3. **Submit Feedback & Pull Requests**: Found ways to improve our canvassing scripts or translate flyers into Spanish, Cantonese, or Arabic? Submit a pull request!
