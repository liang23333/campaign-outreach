# Outreach Flyers Directory

This folder contains the text content, formatting specifications, and distribution guidelines for community flyers across the tour stops.

## Files
- `oakland-stop-flyer.md`: Bilingual (English/Spanish) event flyer copy for Oakland.
- `berkeley-stop-flyer.md`: Event flyer copy for Berkeley.
- `richmond-stop-flyer.md`: Event flyer copy for Richmond.

## Printing & Distribution Guidelines
1. **Paper Specs**: 8.5" x 11" (full-page) or 5.5" x 8.5" (half-page handbills), 100% recycled paper with union bug.
2. **Distribution Radius**: Focus on high-foot-traffic community boards within a 1.5-mile radius of each central library stop (local coffee shops, laundromats, community boards, farmers markets).
3. **Accessibility**: Always include venue transit accessibility details (BART stations and AC transit bus lines) and wheelchair accessibility notes.
